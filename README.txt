项目简介：这是一个基于 C++ 和 Winsock2 开发的简易多人在线聊天室。它支持 多客户端并发连接、用户名设置 和 消息广播 功能。

核心功能：
多客户端并发：采用 std::thread 为每个客户端分配独立线程。
消息广播：客户端发送的消息会由服务器转发给所有其他在线用户。
身份标识：用户连接时需输入用户名，消息会显示发送者身份。

技术栈与工具：
语言：C++11
网络库：Winsock2
构建工具：G++（MSYS2 环境）
版本控制：Git

环境要求：例如“操作系统：Windows 10/11”、“编译器：支持 C++11 的 MinGW”。
运行指南：先开服务器，再开客户端
